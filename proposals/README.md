# Proposing by pull request

You can propose a session or multi-day track for the No-CAP Workshop with a pull request.
The form and email are the other two ways, and are described on
<https://nocap-workshop.com/propose/>.

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to `proposals/<your-name>-<short-title>.md`.
2. Fill it in and open a pull request against `main`.
3. Change it by pushing more commits to the same branch, any time before the proposal
   deadline.

## Before you open one

- **A pull request is public.** Your proposal text, and your name and bio, are visible to
  everyone the moment you open it, before the Steering Committee has decided anything. If
  you would rather keep it between you, the organizer, and the committee, use the form or
  email leads@nocap-workshop.com instead.
- **Leave out your email address.** The organizer will reply on the pull request.
- **Do not edit anything else.** A proposal pull request should add only its own file in
  `proposals/`. The site content, leads, and schedule are changed by the organizer when a
  proposal is approved.
- **A merge is not an approval.** Proposals are judged by the Steering Committee against
  the published criteria in the Lead Agreement. The organizer tells you the outcome on the
  pull request within five business days of the deadline. If it is approved, the organizer
  turns it into the session page. If it is declined, the pull request is closed with a
  short reason on request, and you may resubmit.

Files in this folder are not part of the website, so nothing here is published until the
organizer adds it.
